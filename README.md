# 🚀 Zenithio - Portfolio & Knowledge Hub Template

**Zenithio** হল একটি আধুনিক, হালকা, রেসপন্সিভ এবং দ্বিভাষিক (বাংলা ও ইংরেজি) ওয়েব পোর্টাল টেমপ্লেট। এটি ব্যক্তিগত পোর্টফোলিও, সংস্থা বা ব্লগ সাইট হিসেবে ব্যবহার করার জন্য বিশেষভাবে ডিজাইন করা হয়েছে।

🌐 **Live Demo:** [https://zenithio-web.github.io/Zenithio/](https://zenithio-web.github.io/Zenithio/)

---

## ✨ ফিচারসমূহ (Key Features)

- 🌐 **Multilingual Support:** এক ক্লিকেই বাংলা এবং ইংরেজি ভাষায় স্যুইচ করার সুবিধা।
- 📰 **Interactive Knowledge Hub:** নিবন্ধ ও পপ-আপ মোডাল সহ তথ্যকেন্দ্র।
- 📱 **Fully Responsive:** মোবাইল, ট্যাবলেট এবং ডেস্কটপে সুন্দরভাবে প্রদর্শিত হয়।
- 🎨 **Modern UI/UX:** চমৎকার হিরো ব্যানার, প্রজেক্ট গ্যালারি এবং সার্ভিস সেকশন।
- ✉️ **Contact Form:** ক্লায়েন্টদের যোগাযোগের সুবিধার্থে ডায়নামিক কন্টাক্ট ফরম।
